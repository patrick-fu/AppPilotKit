# Domain docs

This repository uses a single-context domain-doc layout.

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read ADRs under `docs/adr/` that affect the area being changed.
- If those files do not exist, proceed without creating placeholders.

## Vocabulary

Use terms defined by `CONTEXT.md` in issues, tests, APIs, and design proposals. If a needed concept is missing, either reconsider the new term or capture the gap for domain modeling.

## Architecture conflicts

If a proposal contradicts an existing ADR, identify the ADR and explain why reopening the decision may be justified. Do not silently override it.
